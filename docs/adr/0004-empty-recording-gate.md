# ADR-0004: Гейт пустой записи до провайдера

- Статус: accepted (2026-11-02, обе платформы)
- Контекст: случайный тап хоткея или «держал, но передумал говорить» уходили в
  провайдер и возвращались ошибкой через 20–40 c; отменить было нельзя.

## Решение

До любого обращения к провайдеру запись гейтится локально
(`AppState.resolveRawTranscript`, шаг 0; Windows — гейт в worker'е `End()` сразу после `recorder.Stop()`, по локальному рекордеру — фикс 2026-11-04, до него гейт читал уже обнулённое поле и был мёртвым кодом):

- длительность < 0.5 c, ИЛИ
- речь < 0.3 c (`SpeechHeuristics`: RMS-профиль, порог = max(шум×3, 0.003),
  15-й перцентиль как пол), ИЛИ
- пик < 0.03 (цифровая тишина)

→ мгновенный локальный результат «Nothing to transcribe», провайдер не зовётся.

## Последствия

Тап/абандон гаснут < 1 c без network I/O; параметры гейта — спека 10 §7.3,
тесты `SpeechHeuristicsTests` (Swift + C#-эталон на тех же кейсах).

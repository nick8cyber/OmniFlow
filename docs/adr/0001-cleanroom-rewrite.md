# ADR-0001: Чистовая переписка OmniFlow

- Статус: accepted (2026-09, ревизия 2026-11-03)
- Контекст: форк FreeFlow оброс историей апстрима; знания размазаны по коду,
  часть решений противоречила потребностям (Gemini, Live, Windows-порт).

## Решение

Полная чистовая переписка на Swift с нуля (`/Users/surja/Projects/OmniFlow`,
репо `nick8cyber/OmniFlow`), переименование в OmniFlow. Передmerge-аудит —
два «слепых» агента по спекам; знание закреплено в `docs/spec/*` (нумерованные
спеки 00–33 вместо ADR до 2026-11-03).

## Последствия

- Апстрим FreeFlow не мёржится; родословная — только в README и CHANGELOG.
- Спеки — источник правды; ADR-каталог (этот) — только про «почему».
- Windows-версия — отдельный кодобаз в `nick8cyber/freeflow` → `windows/`.

# ADR-0008: Брендинг — иконка и отказ от промо в UI

- Статус: accepted (2026-11-03)
- Контекст: иконка наследовала молоток FreeFlow; в UI висело GitHub-промо
  (репо-линк, счётчик звёзд, Star) с сетевым кэшем ради косметики.

## Решение

- Новая иконка: macOS-squircle, сине-фиолетовый градиент, мотив «волна речи →
  строки текста»; dev-сборка — янтарный градиент. Генератор —
  `Resources/generate-app-icon.swift`, регенерация `make icon`.
- GitHub-промо убрано из UI (шапка настроек и welcome-шаг — только иконка/имя/
  версия); `GitHubMetadataCache` и модели удалены; репо остаётся в README.

# ADR-0005: Оверлей — одна карточка

- Статус: accepted (2026-11-01)
- Контекст: существовали «крылья нотча» и pill; пользователь потребовал точный
  порт редизайна Windows-версии (`OverlayForm.cs`) — вольная адаптация была
  отвергнута.

## Решение

Единственный вид оверлея — тёмная карточка 480×64 (градиент #222229→#141419,
рамка #40404A / красная на ошибке, 5-полосный эквалайзер 30 fps, транскрипт
2 строки head-truncate, пилюли REC и «→ App»). Мёртвый ключ `use_compact_overlay`
удалён из настроек и стирается при старте (ADR-0007).

## Последствия

`WaveformView` остаётся только для тестового шага мастера; палитра —
локальная в `RecordingOverlay.swift` (Theme.cs), UI-кит её не наследует.
